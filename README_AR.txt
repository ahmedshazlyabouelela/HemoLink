HemoLink — دليل التشغيل والاستخدام
=================================

تشغيل الداشبورد بدون إنترنت:
1. فك ضغط HemoLink_Offline.zip بالكامل في فولدر واحد.
2. افتح index.html بالضغط مرتين، باستخدام Chrome أو Edge أو Firefox.
3. الحسابات والرسومات تعمل داخل المتصفح؛ لا تحتاج Python أو تثبيت مكتبات.

الداتا الأساسية افتراضية للتعليم ومطابقة للنوت بوك المرفقة.
النموذج لتوزيع منتج دم واحد متوافق، في دورة نقل واحدة.

صفحات الداشبورد:
- Overview: تكلفة النقل، التغطية، الشبكة، ومصفوفة التوزيع.
- Scenario lab: مقارنة 8 حالات وتحليل أثر تغيير السعة.
- Method studio: خطوات NWC وLCM وVAM وحسابات Penalty وMODI.
- Model & audit: معادلات النموذج، فحص القيود، وشهادة الأمثلية.
- Report & exports: تقرير للطباعة، CSV، حفظ واستيراد الحالة JSON.

طريقة العرض:
ابدأ Base (التكلفة 927)، اعرض الطريق الممنوع B1-H4 وسعة B3-H4=18.
من Method studio اختار LCM ثم MODI لعرض التحسين 989 إلى 927.
اختار VAM ثم Construction لشرح الـPenalty، وMODI لإظهار أنه لا يحتاج تحسينًا في هذه الحالة.
اختار Capacity 30: التكلفة 895، والتدفق على الطريق 25 فقط.
اختار Surge +25: تسليم حقيقي 190 من 215، و25 وحدة طلب غير مغطاة.
اختار Stock +20: مخزون متبقٍ 20، وLCM يبدأ أفضل من VAM في هذه الحالة.
اختار Blocked hospital من Scenario lab لشرح أن توازن الإجمالي لا يضمن وجود حل.

التعديل والحفظ:
- تغيير المؤشرات لا يطبق إلا بعد Optimize plan.
- اختيار سيناريو جاهز يطبق فورًا ويبدأ من الداتا الأساسية الحالية.
- Edit inputs في Model & audit يعدل مصفوفة التكاليف والمعروض والمطلوب.
- Restore supplied data يرجع الداتا والإعدادات الأساسية كلها.
- Export case JSON يحفظ الداتا والإعدادات الحالية. Import case JSON يسترجعها.
- قد يحتفظ المتصفح بآخر حالة؛ للاحتفاظ بنسخة مؤكدة استخدم JSON.
- Presentation mode يكبر مساحة العرض. اضغط Esc للخروج.
- Print / Save PDF يفتح نافذة الطباعة؛ اختر Save as PDF.

القيود:
المعروض، المطلوب، عدم السالبية، منع B1-H4، والحد الأقصى B3-H4.
الحالات الإضافية قد تغلق مسارات أخرى.
قيد السعة يطبق على الوحدات في دورة واحدة، وليس مسألة توجيه مركبات.
الـDummy source يمثل طلبًا غير مغطى، وليس دمًا حقيقيًا.
الـDummy destination يمثل مخزونًا متبقيًا، وليس فاقدًا.
غرامات العجز الافتراضية بالترتيب H1–H6: 800،600،600،750،650،500.
يمكن اختيار غرامة موحدة 500 من More settings ثم Optimize.

مقارنة الأساس:
NWC: 1119 → 927 (6 MODI pivots)
LCM: 989 → 927 (3 MODI pivots)
VAM: 927 → 927 (0 MODI pivots)

الحسابات تستخدم تعديلًا يضمن بقاء الشبكة قابلة للحل عند الطرق الممنوعة والسعات.
MODI يدعم حدود السعة، مع شهادة primal-dual يتم حسابها في كل تشغيل.
